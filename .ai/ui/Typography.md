# Typography

## Fonts

- Primary: `Inter`.
- Future Persian: `Vazirmatn`.
- Fallback: system UI stack.

Use Inter for all current Latin UI. When Persian UI is introduced, use Vazirmatn for Persian text while preserving the same hierarchy and spacing rules.

## Type Scale

| Token | Size | Line Height | Weight | Usage |
| --- | ---: | ---: | ---: | --- |
| Display | 48px | 56px | 700 | Rare public page hero or major product signal |
| H1 | 36px | 44px | 700 | Page title |
| H2 | 28px | 36px | 650 | Major section heading |
| H3 | 22px | 30px | 650 | Card group or panel heading |
| H4 | 18px | 26px | 650 | Compact section heading |
| Body Large | 16px | 26px | 400 | Lead copy, important form explanation |
| Body | 14px | 22px | 400 | Default UI text |
| Small | 13px | 20px | 400 | Metadata, table secondary text |
| Caption | 12px | 18px | 500 | Labels, badges, compact helper text |
| Button | 14px | 20px | 600 | Button text |

## Rules

- Use sentence case for labels, buttons, headings, and table headers.
- Do not use all caps for normal UI labels.
- Keep letter spacing at `0`.
- Do not scale font sizes by viewport width.
- Use concise, domain-specific language: service, variant, order, payment, agent, credential, timeline.
- Avoid retail-first terms unless they exactly match the domain.
