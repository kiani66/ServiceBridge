# Navigation

## Navigation Types

- Public.
- User.
- Agent.
- Admin.
- Breadcrumb.
- Sidebar.
- Topbar.

## Public

Public navigation focuses on service discovery, trust, and sign-in. It should avoid retail storefront patterns that imply normal product shipping.

## User

User navigation prioritizes services, orders, payments, credentials, and timeline tracking.

## Agent

Agent navigation prioritizes assigned orders, fulfillment state, credential-safe access, and activity history.

## Admin

Admin navigation prioritizes catalog operations, pricing, orders, payments, agents, and audit-oriented views.

## Rules

- Current location must be visible.
- Breadcrumbs appear on nested operational pages.
- Sidebars are preferred for admin and agent work.
- Topbar supports global account actions and high-value shortcuts.
- Mobile navigation uses a drawer pattern with clear role-specific grouping.
