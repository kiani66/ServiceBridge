# Border Radius

## Tokens

| Token | Radius | Usage |
| --- | ---: | --- |
| Input | 8px | Text inputs, selects, search |
| Button | 8px | Buttons and segmented controls |
| Card | 8px | Cards and contained repeated items |
| Dialog | 12px | Modal dialogs |
| Drawer | 12px | Drawer panel outer corners where visible |

## Rules

- Use 8px as the default radius for controls and cards.
- Avoid overly pill-shaped components unless the control is naturally compact, such as a status badge.
- Nested cards are not allowed.
- Table rows should not use large radius; use borders, spacing, and row states.
