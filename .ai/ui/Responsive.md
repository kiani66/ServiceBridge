# Responsive

## Breakpoints

| Name | Width |
| --- | ---: |
| Mobile | 0px to 639px |
| Tablet | 640px to 1023px |
| Desktop | 1024px and up |

## Desktop

- Use sidebar navigation for agent and admin work.
- Keep toolbars horizontal when space allows.
- Tables may show full operational detail.

## Tablet

- Collapse secondary toolbar actions into menus when needed.
- Use two-column cards only when content remains readable.
- Drawers may remain side panels if width supports it.

## Mobile

- Use drawer navigation.
- Stack form fields and actions.
- Convert dense tables to list rows or card-like row summaries when needed.
- Keep touch targets at least 40px high.
- Do not hide critical payment, credential, or order status information.

## Rules

- Text must fit without overlap at every breakpoint.
- Controls must not shift size when loading or changing state.
- Horizontal scrolling is allowed for dense admin tables only when paired with clear row context.
