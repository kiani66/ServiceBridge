# Drawer

## Purpose

Drawers support contextual detail without leaving an operational list or dashboard.

## Use Cases

- Order details.
- Timeline preview.
- Payment detail.
- Agent assignment detail.
- Filter panels on mobile.

## Rules

- Drawers should not replace full edit flows when the task is complex.
- Keep the triggering page context visible on desktop.
- On mobile, drawers may become full-screen panels.
- Include a clear title, close button, and accessible name.
- Detail drawers must not expose sensitive credentials unless the role and flow authorize it.
- Changes made inside a drawer must have explicit save/cancel actions when persistent.

## Sizing

- Desktop detail drawer: 420px to 560px.
- Desktop filter drawer: 360px to 420px.
- Mobile drawer: full width.
