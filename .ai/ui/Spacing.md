# Spacing

## Scale

| Token | Value | Usage |
| --- | ---: | --- |
| 1 | 4px | Tight icon gaps, compact inline spacing |
| 2 | 8px | Control internals, small gaps |
| 3 | 12px | Label to input, compact stack gaps |
| 4 | 16px | Default component spacing |
| 5 | 20px | Dense section spacing |
| 6 | 24px | Form groups, toolbar gaps |
| 8 | 32px | Page sections, card grids |
| 10 | 40px | Major layout spacing |
| 12 | 48px | Page header spacing |
| 16 | 64px | Large public page bands |

## Rules

- Use the spacing scale for margins, padding, gaps, and layout rhythm.
- Prefer `16px`, `24px`, and `32px` for application surfaces.
- Forms use `8px` label-to-input spacing and `16px` field-to-field spacing.
- Dense admin views may use compact spacing, but must remain scannable and touch-safe.
- Avoid arbitrary one-off spacing unless a component has a documented reason.
