# Icons

## Direction

Icons should clarify action and status without becoming decoration. Use a consistent outline icon style across the app.

## Rules

- Prefer an established icon library already available in the UI stack.
- Use icons in tool buttons, navigation items, status badges, and empty states when they improve scanning.
- Every icon-only button must have an accessible label and tooltip.
- Icons must be paired with text for destructive, financial, or credential-sensitive actions unless space is severely constrained.
- Use status icons with status colors for payment, order, credential, and fulfillment states.

## Sizes

| Context | Size |
| --- | ---: |
| Inline text | 16px |
| Buttons | 18px |
| Navigation | 20px |
| Empty state | 32px |

## Avoid

- Mixed filled and outline icon styles in the same surface.
- Decorative icon backgrounds that compete with data.
- Ambiguous icons for payment, credential, or order actions.
