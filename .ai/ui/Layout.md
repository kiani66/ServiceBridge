# Layout

## Application Shell

- Topbar for global actions.
- Optional role-specific sidebar for user, agent, and admin areas.
- Main content region with constrained width where appropriate.
- Full-width operational tables may use wider content bounds.

## Widths

| Context | Max Width |
| --- | ---: |
| Public content | 1120px |
| Standard app page | 1200px |
| Dense admin page | 1440px |
| Form page | 760px |

## Rules

- Use full-width bands or unframed layouts for major page sections.
- Do not wrap every section in a card.
- Page headers include title, optional description, and primary action.
- Keep toolbars close to the data they control.
- Stable dimensions are required for grids, icon buttons, counters, and toolbar controls to avoid layout shift.
- Text must not overlap or overflow its container on mobile or desktop.
