# Inputs

## Components

- TextBox.
- Password.
- Dropdown.
- Autocomplete.
- Checkbox.
- Radio.
- Switch.
- Search.
- Validation.
- Help Text.

## Anatomy

- Label.
- Input control.
- Optional help text.
- Optional validation message.

## Rules

- Labels are required for every input.
- Placeholder text must not replace labels.
- Credential inputs must default to masked behavior where appropriate.
- Search inputs include a search icon and clear affordance when text is present.
- Validation messages appear below the control and identify the field and corrective action.
- Help text appears before validation when both are present, but validation gets stronger visual emphasis.

## States

- Default.
- Hover.
- Focus.
- Filled.
- Disabled.
- Read-only.
- Invalid.
- Loading, for autocomplete or remote option fetching.

## Sizing

- Default height: 40px.
- Compact height: 32px for dense tables and filters.
- Touch targets should not be smaller than 40px on mobile.
