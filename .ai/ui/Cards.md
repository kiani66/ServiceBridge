# Cards

## Direction

Cards represent discrete repeated items or compact summaries. Do not use cards as generic page-section wrappers.

## Types

| Card | Purpose |
| --- | --- |
| Stat Card | Metric, trend, and status summary |
| Price Card | Service variant price and pricing context |
| Order Card | Order status, payment state, and timeline hint |
| Service Card | Service and variant discovery |
| Information Card | Compact supporting information or guidance |

## Anatomy

- Header or title.
- Primary content.
- Optional metadata.
- Optional action area.
- Optional status indicator.

## Rules

- Radius: 8px.
- Use border by default; add low elevation only for interactive cards.
- Keep actions predictable and aligned.
- Price cards must make IRR amount, variant, and pricing context clear.
- Order cards must show status in plain language and avoid hiding payment state.
- Never place a card inside another card.
