# Minimal Prompt Examples

Once installed, prompts can stay short.

## Implementation

```text
$servicebridge-architect Inventory Foundation را طبق وضعیت فعلی repository پیاده‌سازی کن. ابتدا codebase-memory-mcp و سپس source واقعی را بررسی کن. Commit نکن.
```

## Debugging

```text
$servicebridge-architect علت این خطا را در flow پرداخت پیدا و اصلاح کن. تست regression اضافه کن و commit نکن: <error>
```

## Code review

```text
$servicebridge-architect تغییرات branch فعلی را برای merge review کن. فقط findingهای واقعی با severity، مسیر، اصلاح و تست لازم را گزارش بده.
```

## Planning

```text
$servicebridge-architect قدم بعدی critical path را از روی repository تعیین کن و یک plan اجرایی PR-sized بده.
```

## Commit after review

```text
$servicebridge-architect تغییرات فعلی را validate کن؛ اگر کامل و امن است commit مناسب بساز، ولی push نکن.
```
